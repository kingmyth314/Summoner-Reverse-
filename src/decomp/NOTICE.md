# Notice for `src/decomp`

The files in this folder are a reconstruction, in C++, of the program code of `Sum.exe`, the executable of the
PC game **Summoner** (version 1.40), developed by Volition and published by THQ in 2000. They were written by
reading the disassembly of a legitimately owned retail copy, for study, interoperability with modern systems,
and preservation.

  Summoner, its code, text and data remain with their owner.
- **Nothing from the game is included** apart from what the reconstructed code itself has to contain to behave
  the same: the program's own text strings and constants. No game data, art, sound, levels or executables are in
  this repository, and none are needed to read it. To build or run anything you need your own copy of the game.
